# Lainon Sethabela — personal founder website

A static portfolio for Lainon Mohlape Sethabela, founder of TechTray Holdings.

## Publish with GitHub Pages

Intended account: `techtrayholdings-shop`.
Repository: `my-techaccessory-shop`.
Website directory: `lainon-sethabela/`.
Publishing source: existing GitHub Pages deployment from branch `main`, folder `/(root)`. Add this directory as `lainon-sethabela/` without changing existing store files.
Expected URL after successful publication: `https://techtrayholdings-shop.github.io/my-techaccessory-shop/lainon-sethabela/`.

All images, fonts, styles and scripts use relative paths so the site works at a GitHub Pages project URL. No build step, API keys or server are required. `.nojekyll` preserves the static files.

## Website

- Authentic founder portrait and official TechTray logo.
- Eduvos and Alumni Association branding examples.
- Separately labelled NWU Student Life concepts.
- Accessible project galleries, mobile navigation, direct contact links and a WhatsApp enquiry builder.

The enquiry form prepares an editable WhatsApp message. It does not store submissions or send messages automatically.

## Editing

Edit `index.html` for page content, `app.js` for gallery content and interactions, and `styles.css` for presentation. Site images and local fonts are in `assets/`. See `assets/font-licenses.txt` for font notices.

The TechTray online store is a separate project and is not changed by publishing this site.
